# Agent Motto Battle

A one-line program for the [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d) bounty on make.fun: it writes a single short original motto an AI agent would proudly put on its profile to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The program writes one line of plain text (at most 200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, defaulting to `/output/entry.txt`.
